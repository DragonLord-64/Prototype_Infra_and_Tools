{{ include "air-gapped-mirror.fullname" . }} is installed in namespace {{ .Release.Namespace }}.

Watch it come up (all 3 containers should reach Running):

  kubectl -n {{ .Release.Namespace }} get pods -w
  # or just: k9s -n {{ .Release.Namespace }}

Clients on the internal network reach it at these in-cluster addresses:

  git    git://{{ include "air-gapped-mirror.fullname" . }}:{{ .Values.service.ports.git }}/<repo>.git
  pip    pip install --index-url http://{{ include "air-gapped-mirror.fullname" . }}:{{ .Values.service.ports.pypi }}/root/pypi/+simple/ \
           --trusted-host {{ include "air-gapped-mirror.fullname" . }} <package>
  apt    Acquire::HTTP::Proxy "http://{{ include "air-gapped-mirror.fullname" . }}:{{ .Values.service.ports.apt }}";

(--trusted-host is required: pip silently ignores a plain-HTTP index without it.)

To reach it from your laptop instead, port-forward:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "air-gapped-mirror.fullname" . }} 9418:{{ .Values.service.ports.git }}
  git clone git://localhost:9418/<repo>.git

{{ if .Values.syncJob.enabled -}}
The sync sidecar mirrors {{ len .Values.syncJob.repos }} repo(s) every {{ .Values.syncJob.intervalSeconds }}s. It is quiet
on purpose: it logs only when something actually changes or fails, so an
empty log means "up to date".

  kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "air-gapped-mirror.fullname" . }} -c sync -f

To change the repo list, edit syncJob.repos and re-run helm upgrade. The
mounted manifest refreshes in place, so no restart is needed.
{{- else -}}
The sync sidecar is DISABLED, so nothing is populating the git volume yet.
devpi (pip) and apt-cacher-ng work regardless -- they cache on demand. To
enable mirroring, list the repos you want and re-run helm:

  --set syncJob.enabled=true \
  --set syncJob.repos[0].name=widgets \
  --set syncJob.repos[0].url=https://github.com/your-org/widgets.git \
  --set syncJob.repos[0].dest=your-org/widgets

(Past one or two repos, put them in a values file instead.)
{{- end }}
